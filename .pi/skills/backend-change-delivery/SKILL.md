# 后端变更交付

用于把一项后端需求交付成可验证的行为，不替用户扩大功能范围或自动部署。先读[数据真相与契约](../../../docs/工程规范/01-数据真相与契约.md)与[接口与写入](../../../docs/工程规范/02-接口与写入.md)；若涉及数据库，再读[迁移与数据修复](../../../docs/工程规范/03-迁移与数据修复.md)。

## 执行方式

1. 找到项目现有接口契约、数据模型、测试习惯及调用方；写出本次变更的权威数据来源、验收场景和旧客户端影响。保持项目既有风格，不机械套用新响应格式。
2. 先补关键契约测试，再实施最小范围的接口和领域变更。写入操作逐一检查身份来源、对象归属、幂等范围、数据库约束和并发结果。
3. 涉及模型变更时提供版本化迁移和历史数据处理方案；不得将迁移执行或数据修复默认为已授权。
4. 运行与风险相称的类型、测试、构建和模型校验；核对实际调用方字段及空值行为。

## 输出

说明实现行为、测试结果、尚未验证的环境条件和发布注意事项。若用户只要求方案或诊断，停在分析，不修改代码。
