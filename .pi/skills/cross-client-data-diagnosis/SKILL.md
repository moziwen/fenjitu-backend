# 跨端数据一致性诊断

先读[数据真相与契约](../../../docs/工程规范/01-数据真相与契约.md)和[验证发布与观测](../../../docs/工程规范/04-验证发布与观测.md)。目标是找出差异产生的层级，而不是先认定前端或后端有错。

## 诊断路径

1. 固定可比条件：环境、客户端版本、账号与实体、操作时间、筛选条件、时区和缓存状态。缺少其中关键条件时标注不确定性。
2. 分别追踪页面的数据入口、网络请求、服务端处理、数据库记录和资源地址；区分“未发请求”“请求失败”“响应不同”“响应相同但渲染不同”。
3. 对比字段定义、排序、分页、可空值和本地缓存或派生逻辑。使用请求标识或脱敏标识关联日志；不索取或输出令牌、密码与完整个人数据。
4. 给出可复现步骤、证据、最可能原因及尚待验证的假设；建议修复位置和回归用例。

## 停止条件

只读诊断不能自行改写记录、清缓存、发布客户端或替用户登录。若必须做这些操作才能确认结论，列出所需授权和最小验证方案。
