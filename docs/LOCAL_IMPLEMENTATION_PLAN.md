# 本地实施计划

## 状态

最小样板已实现并完成本地验证；dev-loop 项目级代理的工具白名单已修复，PI WEB 中的只读子代理验收已通过。完整开发流程尚未重新验收。

## 目标

验证 PI WEB 能在本地仓库启动 dev-loop 实施流程，并产出可运行、可测试、可查看 Swagger 的最小 FastAPI 后端。

## 实施范围

- 提供 `GET /health` 健康检查接口。
- 使用 FastAPI 自带的 `/docs` 和 `/openapi.json`。
- 为接口和文档添加最小自动化测试。
- 依赖仅安装在项目本地 `.venv`。
- 提供中文启动说明。

## 不在本次范围内

- 数据库、认证、业务接口及部署配置。
- GitHub issue、PR、提交或推送。
- 把 FastAPI 视为最终技术选型。

## 验收标准

- 自动化测试通过。
- 服务仅监听 `127.0.0.1`。
- `/health`、`/docs`、`/openapi.json` 均返回 HTTP 200。
- `.venv` 和临时缓存不进入 Git 暂存区。

## 已验证结果与剩余风险

两项自动化测试通过，三个端点均已通过真实 HTTP 请求验证。此前 dev-loop 本地实施在回收结果时曾因工具白名单配置报错；修复后，PI WEB 中的只读子代理及外层编排均成功完成，未再出现该错误。完整开发流程仍需单独验收。
